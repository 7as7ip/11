LAITNO · اپ Native Kotlin · راهنمای کامپایل کامل

━━ مرحله ۰: نصب ابزار (یکی ۲۰ دقیقه) ━━
۱) Android Studio رو نصب کن: https://developer.android.com/studio
۲) اول بار باز کنی، خودش Android SDK و Gradle رو میگیره (حدود ۵GB)

━━ مرحله ۱: Firebase ━━
۱) firebase-config.js موقت رو باز کن و API_KEY + PROJECT_ID رو بذار
   (موقتاً نیازی به جدول "users" نیست، محض ثبت‌نام کافیه)
۲) در Firebase console، Authentication → Email/Password رو Enable کن

━━ مرحله ۲: کامپایل درون Studio ━━
۱) Android Studio → File → Open → این پوشه رو انتخاب کن
۲) صبر کن تا همه‌ی Dependencies دانلود بشه (اول اجرا ۵-۱۰ دقیقه طول می‌کشه)
۳) Run → Run 'app'
۴) اگه گوشی داری و ADB فعال کردی، مستقیم روی گوشی نصب می‌شه
   (اگه نه: Emulator درون Studio رو بزن)

━━ مرحله ۳: Release APK (برای انتشار) ━━
۱) Build → Generate Signed Bundle / APK
۲) Create new → رمز: هر چی (فقط نیاد یاد داشت)
۳) Key password = Store password
۴) Build Variants: release
۵) Build type: release
۶) Finish
→ فایل APK توی app/build/outputs/apk/release/ بیاد.
→ اپ نهایی برای کافه‌بازار و مایکت آماده‌ست.

━━ مرحله ۴: رفع اگر مشکل داشت ━━
- اگه خطا «Cannot find...» داد: Gradle Sync → Sync Now
- اگه Gradle Daemon crash کرد: File → Invalidate Caches
- اگه Emulator نمی‌خورد: Device Manager → Create device جدید

━━ نکات ━━
- کل اپ Kotlin نوشته شده، مع لغات و منطق.
- UI با Jetpack Compose (Modern Android UI framework).
- Firebase integration بدون SDK کسری (و به همین دلیل سبک).
- تمام ۱۲ صفحه کاملاً interactive و روان.

━━ بعدی ━━
اگر خروج آپدیت از رهنما را کردید:
- versionCode و versionName در app/build.gradle رو افزایش بده
- Release APK جدید رو بساز و توی مارکت آپدیت کن.
